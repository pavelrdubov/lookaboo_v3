# План работ

## Код

- [ ] **Сделать модули независимыми.** Сейчас файлы в `js/` — обычные скрипты с общими глобальными
  переменными: кнопки в разметке вызывают функции через `onclick="..."`, поэтому порядок подключения
  в `index.html` важен. Шаг: перевести на ES-модули (`import`/`export`), обработчики навесить из JS
  вместо `onclick` в разметке, состояние (`S`, `WISH`, `TRIPS`, …) отдавать через явные функции.
  Делать, когда кода станет заметно больше; проверять тем же попиксельным сравнением экранов.

## Ждёт решения или материалов

- [ ] **Обратная связь без почтовой программы.** Отправлять отзыв прямо из приложения через Web3Forms
  (нужен ключ, который выдают на web3forms.com по вашей почте) или через функцию на Cloudflare.
- [ ] **Костюмы к праздникам.** Картинки: Хэллоуин (тыква, привидение, летучая мышь, тигрёнок/котик),
  Новый год (оленёнок, гномик/Санта, снежинка/зайчик). Формат как у вещей в `img/`, `.webp`.
