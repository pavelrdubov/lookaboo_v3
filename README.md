# Lookaboo — как положить на свой хостинг

## Как устроен код
Сборки нет: браузер грузит файлы как есть.

- `index.html` — разметка всех экранов и подключение файлов ниже.
- `css/` — стили по разделам: `base` (общее), `onboarding`, `today` (главный экран, шторка, меню),
  `wishlist`, `wish-add`, `plan`, `plan-event`, `trip`, `wardrobe`, `profile`, `sizes`, `shared` (список по ссылке).
- `js/` — модули в порядке подключения:
  `catalog` (список картинок, собирается скриптом) → `data` (наборы, выбор картинок, рост и размеры) → `state` (хранилище, дети) → `onboarding` (переходы между экранами, знакомство) →
  `weather` (город, геолокация, прогноз, климат) → `today` (главный экран) → `share` (картинки для шеринга) → `demo` →
  `wishlist` → `sizes` → `plan` → `trip` → `kid-name` → `wardrobe` → `profile` → `boot` (подгонка макета и запуск).
- `img/` — картинки вещей по папкам (`base`, `mid`, `outer`, `acc`, `stroller`, `toys`, `fancy`, `costume`);
  каталог `js/catalog.js` собирает `python3 tools/catalog.py`. Как называть и добавлять картинки — **IMAGES.md**.

Файлы — обычные скрипты с общими глобальными переменными (кнопки в разметке вызывают функции через `onclick`),
поэтому порядок подключения в `index.html` важен: `boot.js` всегда последний.

В папке всё, что нужно. Ничего собирать не надо.

## Вариант 1. Netlify Drop — 30 секунд, без регистрации
1. Открой на компьютере https://app.netlify.com/drop
2. Перетащи туда ЭТУ ПАПКУ целиком (не отдельные файлы).
3. Получишь адрес вида https://random-name-123.netlify.app — он сразу работает.
4. Бесплатный аккаунт даёт переименовать сайт во что-то человеческое.

## Вариант 2. Cloudflare Pages — тоже бесплатно, чуть надёжнее
1. https://pages.cloudflare.com → Create project → Upload assets
2. Перетащи папку, нажми Deploy.

## Вариант 3. GitHub Pages
1. Создай репозиторий, загрузи файлы в ветку main.
2. Settings → Pages → Source: main / (root) → Save.
3. Адрес появится через минуту: https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПО/

## Дальше — на айфон
1. Открой полученный адрес в Safari.
2. Поделиться → «На экран «Домой»».
3. Появится иконка, приложение откроется на весь экран без адресной строки.

## Что заработает на настоящем хостинге
- геолокация (Safari требует https — на хостинге он есть);
- запрос погоды к Open-Meteo (бесплатно, без ключа и регистрации);
- сохранение настроек между запусками.

## Чего на айфоне не будет, что бы мы ни делали
- виджета на домашнем экране;
- обновления погоды в фоне (данные подтянутся при открытии).
Для этого нужна нативная обёртка и аккаунт Apple Developer.
